# 微词

离线可用的中文诗词格律与创作工具。打开网页即可写诗填词、校验平仄与押韵、查询韵书、鉴赏历代作品，并把成品排成带纸纹与印花的 A4 PDF。

## 快速开始

1. 双击 `index.html`，或运行 `打开微词.bat`。
2. 无需安装依赖，也无需联网；建议使用 Chrome 或 Edge。
3. 完整操作说明见 [`使用说明.md`](使用说明.md)。

## 主要功能

- **格律写作**：16 种近体诗格式、157 个词牌；逐字标注平仄、韵脚与可平可仄位置。
- **韵书查询**：《词林正韵》与《中华新韵》，支持按部浏览、搜索、点击已输入字查韵。
- **鉴赏与检索**：内置 4 万余首诗词文曲，支持作者、朝代、体裁、词牌筛选与全文搜索。
- **默写与集句**：支持隐去部分句子默写、从常用字与韵脚词中挑字成句。
- **统一 PDF 预览**：写作页、例作、格律详解、我的作品、鉴赏详情共用同一套 A4 预览与打印页面。
- **排版与美化**：常规与艺术字体、字重、字号、行距、字距、对齐、横排 / 竖排；配色样式、字色、纸色、纸纹、纸面印花图样。
- **内置字体**：小篆、馆阁体随仓库分发，无需本机安装即真实生效（SIL OFL 1.1，子集化后改名 `WeiCi Xiaozhuan` / `WeiCi Guange`）；其余艺术字体与瘦金体按本机安装情况出现。
- **繁简转换**：查看与导出时可选原文 / 繁体 / 简体，词组优先转换；不改动原稿。
- **云作品与登录**：手机号验证码登录，支持微信登录（需发布到 HTTPS 域名后）；登录后上传作品正文与附件，云端保存、跨设备取回，按用户隔离。
- **本地保存**：未登录时作品与界面设置保存在浏览器本地。

## 内置字体

| 菜单项 | 字体族名 | 字形来源 | 授权 | 覆盖 |
| --- | --- | --- | --- | --- |
| 小篆（内置） | `WeiCi Xiaozhuan` | Chine-Culture Xiaozhuan v1.000，字形取自 Wikimedia Commons「Ancient Chinese characters」公有领域项目 | SIL OFL 1.1 | 约 2755 常用字 |
| 馆阁体（内置） | `WeiCi Guange` | 关哥馆阁体 GuanGe Kai v1.7.3，字形源自明《四書白文》写本（旧传姜立纲），書格 shuge.org 扫描数字化 | SIL OFL 1.1 | 7089 字，不含拉丁字母与数字 |

- 两款字体均做了**子集化**（只保留项目实际用到的约 7755 字，另加繁体补充分片），属 OFL 许可中的「修改」，因此已按 Reserved Font Name 要求改动族名与全名，说明与重新生成命令见 [`fonts/README.txt`](fonts/README.txt)，授权原文见 `fonts/OFL-guange.txt`、`fonts/OFL-xiaozhuan.txt`。
- 字体采用 `font-display: swap` 与按需 `document.fonts.load()`：首屏不下载任何字体文件，只在选中时才解码对应 WOFF2（馆阁体约 3.3MB），字形就绪后自动重排预览。
- 小篆字库只收「有古文字形」的字，缺字（如「和」「炉」「蚁」「暮」）回退楷体，属字库收录范围限制；馆阁体缺拉丁字母与数字，遇到时同样回退楷体。
- **瘦金体 / 宋徽宗瘦金书 / 汉仪瘦金书没有可确认合法授权的开源字库**，无法内置，菜单中仅在本机已安装具备商用授权的字体时出现，否则回退楷体。

## 数据与许可

- 词林正韵、中华新韵、诗格律与词谱数据用于离线查询。
- 繁简转换使用 OpenCC 词库，许可证见 `data/opencc-LICENSE.txt`。
- 内置字体（小篆 / 馆阁体）为 SIL OFL 1.1，许可证见 `fonts/OFL-*.txt`；因做过子集化，已按 OFL 要求改名，不沿用原保留字体名。
- 诗词集注评数据来自 chinese-gushiwen（MIT）；全宋词、元曲、花间集、南唐词等来自 chinese-poetry（MIT）。
- `backgrounds/` 与 `music/` 中的文件可自行替换；缺失时界面会给出提示。

## 说明

本项目为纯静态网页，所有数据均在本地读取。若浏览器限制本地文件访问，可用任意静态服务器打开当前目录。
