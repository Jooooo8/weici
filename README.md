# 微词

离线可用的中文诗词格律与创作工具。打开网页即可写诗填词、校验平仄与押韵、查询韵书、鉴赏历代作品，并把成品排成带纸纹与印花的 A4 PDF。

## 快速开始

1. 双击 `index.html`，或运行 `打开微词.bat`。
2. 无需安装依赖，也无需联网；建议使用 Chrome 或 Edge。
3. 完整操作说明见 [`使用说明.md`](使用说明.md)。

## 主要功能

- **格律写作**：16 种近体诗格式、157 个词牌；逐字标注平仄、韵脚与可平可仄位置。
- **韵书查询**：《词林正韵》与《中华新韵》，支持按部浏览、搜索、点击已输入字查韵。
- **鉴赏与检索**：内置 4 万余首诗词文曲，支持作者、朝代、体裁、词牌筛选与全文搜索。
- **默写与集句**：支持隐去部分句子默写、从常用字与韵脚词中挑字成句。
- **统一 PDF 预览**：写作页、例作、格律详解、我的作品、鉴赏详情共用同一套 A4 预览与打印页面。
- **排版与美化**：常规与艺术字体、字重、字号、行距、字距、对齐、横排 / 竖排；配色样式、字色、纸色、纸纹、纸面印花图样。
- **繁简转换**：查看与导出时可选原文 / 繁体 / 简体，词组优先转换；不改动原稿。
- **本地保存**：作品与界面设置保存在浏览器本地。

## 目录结构

```text
index.html          页面入口
styles.css          样式
app.js              主程序
使用说明.md         完整说明
data/               韵书、词谱、诗格律、作品数据与繁简词库
backgrounds/        五套页面背景图
music/              背景音乐
tools/              数据构建与质检脚本
```

## 数据与许可

- 词林正韵、中华新韵、诗格律与词谱数据用于离线查询。
- 繁简转换使用 OpenCC 词库，许可证见 `data/opencc-LICENSE.txt`。
- 诗词集注评数据来自 chinese-gushiwen（MIT）；全宋词、元曲、花间集、南唐词等来自 chinese-poetry（MIT）。
- `backgrounds/` 与 `music/` 中的文件可自行替换；缺失时界面会给出提示。

## 说明

本项目为纯静态网页，所有数据均在本地读取。若浏览器限制本地文件访问，可用任意静态服务器打开当前目录。
